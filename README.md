# 校园失物招领小程序

2026秋软件工程结对作业（第二次之程序实现）

## 一、项目说明

本项目是一个面向校园的轻量级失物招领 Web 应用，帮助同学们集中发布和查看寻物、招领信息，并通过物品名称关键词进行搜索，提高校园失物寻找和归还的效率。

主要功能：

- 浏览失物和招领信息
- 发布寻物信息
- 发布招领信息
- 按物品名称搜索
- 查看物品详情
- 标记为“已找到”或“已归还”
- 一键复制联系方式

本次作业不涉及后台管理、实名认证、即时聊天、地图定位等功能。

## 二、技术栈

- HTML5
- CSS3
- 原生 JavaScript（ES6）
- localStorage（浏览器本地存储，无需后端）

## 四、使用说明

本项目为纯前端项目，**无需安装任何环境，无需启动服务器**。

### 运行步骤

1. 将整个项目文件夹下载到本地。
2. 使用 **Google Chrome 浏览器** 打开 `index.html`。
3. 即可使用全部功能。

### 功能操作

**浏览信息**

打开 `index.html`，首页会按发布时间倒序展示所有信息。点击任意卡片可进入详情页。

**搜索信息**

在首页顶部搜索框输入物品名称关键词，点击“搜索”或按回车，列表会显示匹配结果。搜索无结果时显示“暂无信息”。

**分类筛选**

点击“全部 / 寻物 / 招领”标签，可按类型筛选信息。

**发布信息**

点击底部导航“发布”，或直接打开 `publish.html`。选择类型（寻物/招领），填写物品名称、地点、联系方式等，点击“发布信息”。必填项未填写时会弹出提示。发布成功后自动返回首页。

**查看详情**

在首页点击任意卡片，进入 `detail.html?id=xxx`，可查看物品的完整信息。

**复制联系方式**

在详情页点击联系方式旁的“复制”按钮，可将联系方式复制到剪贴板。

**修改状态**

在详情页点击“标记为已找到”（寻物）或“标记为已归还”（招领），状态更新后按钮变为“已完成”，不可再次点击。

**运行单元测试**

打开 `test.html`，页面会自动运行 8 个测试用例，并显示通过/失败数量。也可以按 F12 打开控制台查看结果。

## 五、数据存储说明

所有数据存储在浏览器的 **localStorage** 中，键名为 `items`，格式为 JSON 数组。

单条数据格式示例：

```json
{
  "id": 1696752000000,
  "type": "寻物",
  "name": "黑色雨伞",
  "desc": "伞柄有磨损",
  "place": "图书馆三楼",
  "time": "2026-10-08 09:24",
  "contact": "138xxxx1234",
  "status": "进行中"
}
```

注意：

- 数据仅保存在当前浏览器中，清除浏览器数据会丢失。
- 运行 `test.html` 会清空 localStorage，测试后需重新发布数据。

## 六、单元测试

测试文件为 `test.html`，测试逻辑在 `js/test.js` 中。

共 10 个测试用例，覆盖：

1. 添加信息
2. 搜索命中
3. 搜索无结果
4. 按 id 查找
5. 更新状态
6. 删除信息
7. 空关键词搜索
8. 按类型筛选
9. 新增信息默认状态
10. 更新不存在的 id 返回 false

采用白盒测试思路，针对 `searchItems` 函数的空关键词和非空关键词两条分支分别设计用例。
